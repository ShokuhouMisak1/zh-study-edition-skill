# 写作规范 (中文讲解 + 英文术语)

读者是正在用英文原版上课、做作业的中国学生。他们要的不是 “中文版教材”，而是一份**能对照原文、把没讲清楚的地方讲清楚**的学习材料。下面每条规范都从这个目的出发。

## 1. 术语: 用原文的英文

- 所有专有名词、定理名、算法名、问题名、带定义的形容词 (feasible / optimal / degenerate …) 一律用**原文的英文写法**。学生的作业、考试、讲义、Piazza 都用英文词；中文译名 (如 “检验数”“转轴”“择一定理”“全幺模”) 反而让人对不上号。
- **以原文为准**：原文 index / 定义处 / 粗体词的写法、大小写、连字符 (half-space, non-basic, Simplex Algorithm) 都照抄。拿不准就 grep 原文。
- 保留中文的只有非常基础的数学词：矩阵、向量、集合、函数、变量、约束、目标函数、方程、不等式、行、列、秩、行列式、线性组合、线性无关、单位矩阵、维数、子集、分量等。这张 “保留中文” 表在项目开始时和术语表一起定下来，全书统一。
- 写法：
  - 中英文之间加半角空格：`一个 basic feasible solution 是……`
  - 行文小写 (`reduced cost`)，专名按原文大小写 (`Strong Duality Theorem`, `Farkas Lemma`)。
  - 中文无复数，一般用单数；固定说法 (reduced costs) 可用复数，全书一致即可。
  - 形容词/状态：`若 (P) 是 infeasible 的`、`$\bar x$ 是 optimal 的`；动作：`进入 basis / 离开 basis`、`做一次 pivot`。读起来要通顺，必要时调整语序。
  - **不要**给英文术语加中文括注 (“reduced cost (检验数)”)。例外：在某个 “补充讲解” 里专门说明 “中文教材常把 X 译作 Y”，一次即可，帮学生查中文资料时对得上。
- 定义处用 `\emph{...}` 并加索引 `\index{basic feasible solution}` (纯英文、无 `@` 排序键)，书末索引按英文字母排序，与原文索引对得上。

## 2. 结构与标题: 与原文一一对应

- `\chapter`、`\section`、`\subsection`、`\paragraph` 标题用**原文英文标题原文**；习题节叫 `Exercises`。学生翻原书、对照 syllabus 时能直接定位。
- 定理类环境的可选参数只写原文英文名：`\begin{theorem}[Strong Duality Theorem]`。环境名 (定理 / 引理 / 例 / 证明) 是模板生成的中文，不动。
- 章节、例题、习题编号与原文一致；label 用原编号 (`\label{thm:6.3}`, `\label{exo:4.2}`)，方便跨章引用和并行分工。注意 AJbook 按 section 编号 (原文 “Theorem 6.3” 印成 “定理 6.2.1”)，这是模板设定，不必改；label 保留原编号即可。
- 课件改编时，在对应段落末尾用 `\slideref{12}` 标注出自第几页 slide。

## 3. 原文内容: 完整、忠实

- **完整翻译**负责的部分：正文、定理、证明、例子、算法、图、表、代码、习题、尾注。不要删减或概括原文 (学生要拿它对照原文)。
- 原文代码原样保留 (可加中文注释)。
- 数学公式照原文，公式在抽取的文本里常被打乱，一律对照渲染出的页面。
- 发现原文笔误就改正，并用 `\yizhu{原文写作 …, 应为 …}` 说明。不要悄悄改。

## 4. 补充讲解: 这是本版的价值所在

原文跳步、一句带过、“易见”“留给读者”、直觉没交代的地方，要**尽可能讲细**。所有新增内容必须放在 `\begin{jiedu}[标题] … \end{jiedu}` 里，或写成 `\yizhu{…}`，与原作者的文字严格分开 (开放许可通常要求标明改动；也让学生知道考试以原文为准)。

值得加讲解的典型位置：
- 证明中跳过的步骤、“显然”“易验证” 的地方：补全，并说明每一步用到了什么。
- 定义/定理的**为什么**：为什么需要这个假设，去掉会怎样 (给反例)。
- 抽象结论配一个**小的数值例子**，最好能接续书中前面的例子，贯穿全章。
- 几何意义、直觉、与前后章节的联系。
- 常见误解。

数值例子里的每个数都要**用代码验证** (python3 + numpy / scipy / sympy)，不能凭心算。验证脚本放在项目的 `figures/` 或 `scripts/` 里，或至少在报告里说明验证过。

jiedu 标题用中文叙述 + 英文术语：`\begin{jiedu}[为什么 reduced cost 全部非负就 optimal]`。

## 5. 图

- 原作者画的示意图可以从 PDF 裁出来用 (`pdftoppm -r 300 -x -y -W -H`)，更好的是按原文数据用 matplotlib / TikZ 重画 (清晰、可改)。图中文字用英文 (避免字体缺失，也与术语规范一致)。
- 原文中取自网络的照片、漫画、插画、商标图**不要收录**，在原位置用 `\yizhu` 说明省略了什么。
- 图注、表格里的术语同样用英文。

## 6. 习题

- 习题要完整翻译。
- **不写完整解答**。最多在 `\yizhu` 里给思路方向，不给结论推导全过程。这份材料是给正在上课的学生用的，给出答案会变成作业抄袭工具。

## 7. 标点与格式

- 与模板示例一致：中文正文用半角 `, .` 加空格 (或全文统一用全角 “，。”，二选一，全书一致)。
- 行内公式 `$...$` 两侧加空格。
- 不要用 `$$ ... $$`，行间公式用 `\[ ... \]` 或 `equation` / `align`。
